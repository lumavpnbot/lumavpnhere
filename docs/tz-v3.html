01 · Общее описание

О продукте

LUMA VPN — сервис безопасного и быстрого VPN-подключения с обходом белых списков (Чебурнет), реализованный как Telegram Mini App. Мы запускаем лёгкий MVP с бюджетом 1 000–2 000 ₽, фокусом на простоту и органический рост через реферальную программу.

Миссия

Дать каждому пользователю Telegram доступ к свободному интернету за 30 секунд — даже в условиях белых списков мобильных операторов.

Видение

Стать самым удобным VPN-сервисом для русскоязычной аудитории Telegram с обходом белых списков и минимальным порогом входа.

Цели MVP

500 активных пользователей за 2 месяца, 50 платных подписок, стабильный обход белых списков на всех операторах.

Принципы

Простота важнее фич. Обход блокировок — приоритет. Прозрачность важнее маркетинга. Органика важнее платной рекламы.

Ключевое отличие: LUMA VPN не просто «VPN», а решение для обхода белых списков мобильных операторов (Чебурнет). Это главный технический вызов и главное конкурентное преимущество.

04 · Функционал

Экраны и модули Mini App

MVP состоит из 6 экранов. Каждый экран описан с требованиями по состоянию, действиям и обработке ошибок.

4.1 Авторизация и онбординг

  • Вход через Telegram WebApp initData — без пароля и SMS.
  • Валидация hash initData на бэкенде по секрету бота (HMAC-SHA256).
  • Проверка auth_date: не старше 24 часов.
  • Создание профиля: tg_id, username, avatar, referrer_id.
  • При первом входе — автоматическая активация Trial 7 дней.
  • Состояния: Free Trial Active Expired
  • Обработка ошибок: невалидный initData → экран с просьбой перезапустить.

4.2 Главный экран

  • Кнопка «Подключиться» — круглая, 220×220 px, с анимацией.
  • Состояния кнопки: idle → connecting → connected → error.
  • Отображение текущего IP-адреса и локации.
  • Пинг до сервера в реальном времени (обновление раз в 5 сек).
  • Виджет статуса: остаток дней / трафика.
  • Индикатор режима: Прямое подключение / Через туннель.
  • Быстрое переключение между серверами (2 флага сверху).
  • Кнопки: «Скопировать конфиг» / «Показать QR».

4.3 Выбор сервера

  • На старте — 2 локации: Нидерланды и Германия.
  • Карточка сервера: флаг, название, пинг, загрузка в %, статус.
  • Авто-выбор ближайшего сервера по пингу при первом входе.
  • Кнопка «Обновить пинг» — ручной ping через WebSocket.
  • Метки: Free / Premium.
  • Индикатор доступности обхода белых списков для каждого сервера.
  • Заглушка «Скоро: 8 новых локаций» для мотивации к апгрейду.

4.4 Тарифы и подписка

  • Сравнение 3 тарифов в виде карточек (Free / Старт / Про).
  • Переключатель «Месяц / Год» — визуализация экономии.
  • Кнопка «Оформить» → выбор способа оплаты.
  • Активный тариф подсвечивается, дата окончания крупно.
  • Поле ввода промокода с проверкой на бэке.

4.5 Личный кабинет

  • Профиль: аватар, username, tg_id, дата регистрации.
  • Текущая подписка: тариф, дата окончания, автопродление.
  • История платежей с чеками (PDF/скрин).
  • Управление устройствами (список HWID).
  • Активация промокода.
  • Блок «Реферальная программа» (см. раздел 09).
  • Кнопка «Поддержка» → чат с оператором.

4.6 Получение конфига

  • Генерация конфига VLESS + Reality с транспортом XHTTP.
  • Универсальная ссылка vless://... + QR-код.
  • Кнопка «Скопировать» с haptic feedback.
  • Инструкция по подключению для 4 клиентов: Happ, v2rayNG, Streisand, FoXray.
  • Кнопка «Отправить конфиг себе в Saved Messages».
  • Конфиг активен, пока жива подписка (включая Free).
  • При истечении подписки — конфиг аннулируется, выводится экран продления.

Логика обработки платежа

  1. Пользователь выбирает тариф и способ оплаты.
  2. Бэкенд создаёт invoice с уникальным order_id.
  3. Пользователь оплачивает через бота/провайдера.
  4. Webhook от провайдера → проверка HMAC-подписи.
  5. Проверка идемпотентности (защита от дублей).
  6. Обновление подписки в БД + 3x-ui API.
  7. Уведомление в бот: «Подписка активирована».
  8. Начисление реферального вознаграждения (если есть реферер).

Безопасность платежей

  • Проверка подписи всех вебхуков (HMAC-SHA256).
  • Идемпотентность через order_id.
  • Таймаут инвойса — 15 минут.
  • Проверка суммы платежа (защита от фрода).
  • Ручной возврат через админку (только овнер).
  • Полное логирование в отдельной таблице payments_log.
  • Уведомление админу в Telegram о каждой аномалии.

Стек на сервере

  • 3x-ui — панель управления Xray (открытая, бесплатная).
  • Xray-core — движок VLESS + Reality + XHTTP.
  • Nginx + Let's Encrypt (TLS 1.3).
  • Uptime Kuma — мониторинг доступности.
  • Docker + Docker Compose — для бэкенда и БД.
  • Деплой — ручной через git pull + docker compose up.
  • Бэкап БД — cron раз в сутки на S3-совместимое хранилище.

Антиблокировка

  • VLESS + Reality маскируется под обычный HTTPS-трафик.
  • XHTTP разбивает туннель на обычные HTTP-запросы.
  • Основной порт — 443 (наиболее надёжный).
  • Резервный порт — 8443.
  • Собственный домен для каждого сервера.
  • SNI маскировка под разрешённые российские домены (см. раздел 08).
  • Ручная ротация при блокировке (1–2 часа).

План масштабирования

  • 0–500 юзеров: 3 сервера (NL, DE + туннель RU).
  • 500–1500: + 2 сервера (US, FI) — бюджет 30 €/мес.
  • 1500–5000: + 4 сервера (UK, JP, TR, KZ) — бюджет 100 €/мес.
  • 5000+: переход на Marzban + Terraform-автоматизация.
  • Каждый новый сервер окупается при +50 подписчиках.

Мониторинг и алерты

  • Health-check каждые 60 секунд с Uptime Kuma.
  • Алерты в Telegram-чат админов при падении сервера.
  • Проверка CPU/RAM/Disk раз в 5 минут (через node_exporter).
  • Проверка доступности домена из РФ (внешний сервис).
  • Автоматический перезапуск Xray при сбое (systemd).
Бюджет инфраструктуры: 400–600 ₽/мес за три VPS. Окупается при 5–7 активных подписчиках тарифа «Старт».
08 · Обход белых списков

Обход белых списков (Чебурнет)

С марта 2026 года мобильные операторы России (МТС, МегаФон, Билайн, Tele2) блокируют весь трафик, кроме одобренных IP-адресов. Стандартные VPN-протоколы (OpenVPN, WireGuard) не работают. LUMA VPN использует многоуровневую архитектуру обхода.

Ситуация: на мобильном интернете в РФ работает только трафик к «белым» IP-адресам (Яндекс, VK, Госуслуги, банки). Всё остальное режется на уровне оператора. Прямое подключение к зарубежному VPN-серверу невозможно.

8.1 Архитектура обхода: 4 уровня защиты

Уровень 0: Прямое подключение (основной)

  • Устройство → VLESS + Reality → VPS в Нидерландах → Интернет.
  • Для DPI выглядит как обычный HTTPS к www.microsoft.com.
  • Работает на домашнем интернете и части мобильных операторов.
  • Максимальная скорость и минимальный пинг.
  • Используется по умолчанию при наличии доступа.

Уровень 1: XHTTP-транспорт

  • Устройство → VLESS + Reality + XHTTP → VPS за рубежом.
  • XHTTP разбивает туннель на обычные HTTP/2-запросы.
  • Браузерные заголовки (User-Agent, Accept) — имитация веб-сёрфинга.
  • Reality скрывает TLS-рукопожатие, XHTTP — поведение после него.
  • Обходит CIDR-блокировки по IP-адресам.

Уровень 2: Туннель через белый IP

  • Устройство → Туннель (российский белый IP) → VPS за рубежом → Интернет.
  • Туннель — промежуточный сервер с IP из белого списка оператора.
  • Туннель не расшифровывает трафик, только пробрасывает его.
  • Используются IP Yandex Cloud, VK Cloud, Selectel, Timeweb.
  • Скорость ниже, но работает на всех операторах.

Уровень 3: Резервный канал

  • AmneziaWG (WireGuard с обфускацией) — резервный протокол.
  • Случайные размеры пакетов, шум перед handshake.
  • DPI не видит характерную сигнатуру WireGuard.
  • Используется, если VLESS-подходы временно недоступны.
  • Автоматическое переключение между уровнями.

8.2 SNI-маскировка (ключевой метод)

SNI (Server Name Indication) — это домен, к которому обращается пользователь. Операторы пропускают трафик к доменам из «белого списка» (Яндекс, VK, Госуслуги, банки). LUMA VPN маскирует запросы под обращение к этим доменам.

SNI (маскировка под) Работает на операторах Статус
stats.vk-portal.net МТС, Мегафон, Т2, Тмобайл, РТК, Yota Активен
sun6-21.userapi.com МТС, Мегафон, Т2, Тмобайл, РТК, Yota Активен
www.kinopoisk.ru Большинство операторов Активен
vk.com Большинство операторов Нестабилен
Важно: SNI-список обновляется каждые 2 недели. Операторы постоянно меняют белые списки. Мы мониторим ситуацию и оперативно добавляем новые рабочие SNI.

8.3 Требования к туннельному серверу

Характеристики

  • Провайдер: Aeza (RU), VK Cloud или Yandex Cloud.
  • IP-адрес из диапазона белого списка операторов.
  • 1 vCPU, 1 ГБ RAM, 10 ГБ NVMe.
  • Порт 443 (TCP) — маскировка под HTTPS.
  • Пропускная способность: от 100 Мбит/с.
  • Оплата: только рублями, карта РФ.

Ограничения

  • Туннель не расшифровывает трафик — только транзит.
  • Скорость ниже прямого подключения на 20–40%.
  • Пинг +30–60 мс из-за дополнительного хопа.
  • Требуется собственный домен для туннеля.
  • Один туннель на 100–200 пользователей.

8.4 Roadmap обхода белых списков

Этап 1 — Базовый обход (Недели 1–3)

MVP
  • Настройка VLESS + Reality + XHTTP на зарубежных VPS.
  • Ручной подбор SNI, работающих на МТС/Мегафон.
  • Тестирование на 3–5 устройствах с разными операторами.

Этап 2 — Туннель (Недели 4–6)

Обход всех операторов
  • Аренда VPS с российским белым IP (Aeza RU / VK Cloud).
  • Настройка каскада: устройство → туннель → зарубежный сервер.
  • Автоматическое переключение между прямым и туннельным режимом.

Этап 3 — Стабилизация (Месяц 2)

Надёжность
  • Добавление AmneziaWG как резервного протокола.
  • Автоматическое обновление SNI-списка (cron раз в 2 недели).
  • Мониторинг доступности обхода по каждому оператору.

Этап 4 — Масштабирование (Месяц 3+)

Рост

09 · Реферальная программа

Приглашай друзей — зарабатывай

Рефералка — главный канал органического роста LUMA на старте. Механика максимально простая, условия — честные и прозрачные, выплаты — быстрые.

Как это работает

Каждый пользователь получает персональную ссылку вида t.me/LumaVPNBot?start=REF_XXXXXX и делится ей с друзьями.

Что получает реферер

30% от каждого платежа приглашённого на внутренний баланс. Баланс можно тратить на подписку или выводить от 500 ₽.

Что получает приглашённый

Скидка 10% на первую покупку любого тарифа и +3 дня к пробному периоду (итого 10 дней вместо 7).

9.1 Механика начисления

  • Реферальная ссылка генерируется автоматически при регистрации.
  • Приглашённый привязывается при первом запуске по ссылке.
  • Привязка сохраняется навсегда, даже если юзер вернётся позже.
  • Начисление — 30% от суммы каждого платежа реферала.
  • Средства зачисляются на внутренний баланс мгновенно.
  • Холд 7 дней — защита от фрода и возвратов.
  • Реферер получает уведомление в боте о каждом начислении.

9.2 Уровни рефереров

  • Базовый (0–4 реферала): 30% с платежей.
  • Серебро (5–19): 35% + 1 месяц «Старт» в подарок.
  • Золото (20–49): 40% + 1 месяц «Про» в подарок.
  • Платина (50+): 45% + персональная промо-ссылка, вывод без минимума.
  • Уровень закрепляется навсегда — не понижается.
  • Итоговый % применяется ко всем будущим платежам.
  • Уведомление о повышении уровня — push в бот.

9.3 Экран рефералки в Mini App

  • Большая кнопка «Пригласить друга» с шерингом в Telegram.
  • Уникальная ссылка + кнопка «Скопировать».
  • QR-код для офлайн-шаринга (скрин в чат).
  • Счётчики: приглашено / активных / доход за месяц.
  • Прогресс-бар до следующего уровня.
  • Кнопка «Вывести» (активна при балансе ≥ 500 ₽).
  • История начислений с детализацией по каждому рефералу.
  • Краткая инструкция «Как приглашать».
  • Топ-3 реферала месяца (с анонимизацией username).

9.4 Антифрод и правила

  • Запрет приглашать самого себя (проверка по IP, device, платёжным данным).
  • Запрет массового фрода (боты, фейк-аккаунты, накрутка).
  • При выявлении фрода — блокировка баланса и аккаунта без предупреждения.
  • Холд 7 дней на все начисления.
  • Вывод — только на USDT TRC-20 или карту РФ.
  • Минимальная сумма вывода — 500 ₽.
  • Максимум 1 вывод в 7 дней.
  • Обработка вывода — в течение 24 часов вручную.
Почему 30% и уровни: при среднем чеке 149 ₽ вознаграждение реферера — 45 ₽. Это дешевле платной рекламы (CAC 30–80 ₽), плюс приходят «прогретые» пользователи по рекомендации. Уровни стимулируют долгосрочных амбассадоров.

18 · Юридические аспекты

Правовая база

Сервис работает в серой зоне законодательства РФ, поэтому важно правильно оформить юридическую обвязку и минимизировать риски.

Обязательные документы

  • Публичная оферта (услуги VPN-подключения).
  • Политика конфиденциальности (GDPR-совместимая).
  • Условия возврата средств.
  • Правила реферальной программы.
  • Правила использования сервиса (запрет на криминал).

Юрисдикция

  • Регистрация компании: Кипр или ОАЭ.
  • Стоимость регистрации: от 1 500 €.
  • Альтернатива на старте: ИП в РФ (проще, но рискованнее).
  • Платёжный провайдер — европейский или крипто-процессинг.
  • Домен — регистрация через Namecheap или Cloudflare.

Защита данных

  • No-logs политика — не храним историю трафика.
  • Не логируем IP-адреса подключений.
  • Храним только: tg_id, username, дату регистрации.
  • Пароли — Argon2 (только для админки).
  • Бэкапы БД — зашифрованы, на отдельном S3.

Возрастные ограничения

  • Сервис доступен только пользователям 18+.
  • Подтверждение возраста через Telegram-бот.
  • Запрет на использование для криминальной деятельности.
  • Право заблокировать аккаунт за нарушение правил.
